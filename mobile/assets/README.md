# Иконки приложения

Перед запуском Expo добавьте сюда:

- `icon.png` — 1024×1024 px
- `splash.png` — 1284×2778 px (фон #0F172A)
- `adaptive-icon.png` — 1024×1024 px (для Android)

Можно сгенерировать из Logotip2.html или командой:

```bash
npx expo-icon --icon-path ./logo-source.png
```

Цвета бренда: фон `#0F172A`, акцент `#00F0FF`, синий `#0052FF`.
